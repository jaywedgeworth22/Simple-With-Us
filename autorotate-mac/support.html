Autorotate for Mac

Support

Per-app rotation rules, display arrangements, and known-issue reference. If the four checks below don't fix it, send the output to feedback@simplewithus.com and we'll come back the same day.

The four checks that catch 90% of "rule did nothing" reports

  1. Rule toggle is on. The Rules screen shows the toggle on the right. If it's off, the rule is defined but never fires. Toggle on.
  2. Display arrangement selected. If the rule targets an arrangement, the arrangement must be active. Move a display or plug one in to confirm the rule fires when the arrangement matches.
  3. macOS Accessibility permission. The first time the app applies a rule, macOS prompts for Accessibility permission. If you declined, System Settings > Privacy & Security > Accessibility and re-enable Autorotate for Mac.
  4. Display supports rotation. Open Displays in System Settings and look for the rotation dropdown on the affected display. If the dropdown is missing, the display does not expose rotation, and the rule can never apply.

Crash log or "Application keeps closing"

If Autorotate for Mac crashes immediately on launch or after a specific screen, open Console.app on the Mac, filter for "Autorotate", and send the last ~200 lines to feedback@simplewithus.com. If you can repro, note the exact steps and the macOS version (Apple menu > About This Mac).

Rule fired but the display did not rotate

The Diagnostics screen shows recent firings with the response from macOS. If macOS accepted the rule and the display ignored it, the display's EDID does not match its driver. There's no fix from inside the app; contact the display maker. If macOS rejected the rule, the rule's display-arrangement is wrong -- adjust and retest.

Sending logs to support

The app's Settings screen has a "Send Logs" action (under Diagnostics). It bundles the last few minutes into a single zip, scrubbed of your rule names, and opens a prefilled email to feedback@simplewithus.com. Attach the zip; we respond usually within a business day.

Contact

feedback@simplewithus.com -- open a thread, don't worry about templates. Note your macOS version and the display model you were testing.
