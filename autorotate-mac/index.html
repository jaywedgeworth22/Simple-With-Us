macOS display rotation

Per-app rotation rules, with a settings UI that doesn't fight you.

Autorotate for Mac is the macOS sibling of Autorotate.Codes. Pin a vertical display to portrait when Xcode opens. Force a presentation display to landscape when Keynote goes full-screen. Apply rules per-app and per-display-arrangement, with a UI that explains what each rule does and what macOS will and won't let us change.

What's inside

  • Per-app rules. Pick an app, pick a rotation. The rule fires when the app comes forward, per display.
  • Per-arrangement rules. macOS exposes the current display arrangement. Apply a rotation when the arrangement matches -- docked, undocked, external display attached.
  • Native UI. A SwiftUI rule editor, no preferences pane buried in System Settings.
  • macOS LaunchAgent. Optional helper that applies rules at login. Off by default; you opt in.
  • Shared rules with iOS. Optional iCloud Drive sync between the Mac and iOS apps. Rules roam; UI stays native.

How it works

Autorotate for Mac reads the active app and the current display arrangement, then asks macOS to apply the matching rotation rule. macOS exposes display rotation through the standard CoreGraphics APIs; we use those. The app respects the limits of macOS -- some displays report rotation support but ignore the request.

  1. Open the app and add your first rule. Pick the app and the rotation; pick the displays it applies to.
  2. Test by switching to the targeted app. The rotation should apply within a second.
  3. Optionally enable the LaunchAgent to apply rules at login.

What it doesn't do

  • Force displays that ignore rotation. Some external displays report rotation support but apply only portrait/landscape. The rule fires; the display decides. The app surfaces the response in the Diagnostics screen.
  • Touch bar rotation. The Touch Bar has no rotation. We do not touch it.
  • System-wide rotation without a rule. Every action requires an explicit rule. The app never changes rotation behind your back.

Privacy

Autorotate for Mac only needs to manage your rotation rules. No telemetry, no account, no analytics. Rules sync through iCloud Drive if you opt in; otherwise they stay on the Mac. Crash reports are opt-in. Full notice at /privacy.

Need help?

If a rule fires but the display does not rotate, it's almost always the display's EDID lying to macOS. The support page covers the four checks that catch 90% of "rule did nothing" reports; if those don't help, write to feedback@simplewithus.com with your macOS version and the display model.
