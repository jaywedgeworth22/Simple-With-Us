iOS companion for MiniMax Code

Drive MiniMax Code from your phone.

MiniMax Remote is the TestFlight companion for the MiniMax Code runtime. Chat with a session, kick off a new one, edit your scheduled tasks, peek at your other agents. The phone is a remote; the work still happens on the Mac.

What's inside

  • Chat. Live WebSocket to your active session, with markdown that renders (code fences, tables, lists). Multi-line streams assemble correctly.
  • Sessions. See every running and recent session; jump back in with one tap.
  • Scheduled tasks. Review the cron roster, peek at last run, and trigger a one-off run.
  • Your other agents. Browse the agent roster, switch the active agent, send a one-shot instruction.
  • Drive surface. Browse attached files for the active session. Read-only by default; share extension to push a file from another iOS app.

How it pairs

MiniMax Remote talks to a small Swift binary called MiniMax-Companion that runs on your Mac. The Mac side is part of the MiniMax Code install; you start it once (or let the bundled LaunchAgent do it) and the iPhone app finds it on your network via Bonjour. Pair one time with a QR code; the token survives app quit and relaunch on both sides.

  1. On the Mac: open MiniMax Code and confirm the companion server is running. You'll see its Bonjour URL.
  2. On the phone: open MiniMax Remote, tap "Pair", and scan the QR the Mac shows. (Or tap "Manual entry" and paste host/port/token.)
  3. That's it. Chat starts immediately. Settings remembers the pair; Settings -> Forget Pairing if you want to start over.

Wire protocol: the iOS app and the Mac companion implement the same contract at docs/WIRE-PROTOCOL.md in the open-source repo, so neither side changes shape without the other. View source on GitHub.

What it doesn't do

  • Cloud relay. Both sides have to be on the same network. No traffic flows through Simple With Us.
  • Background push. We don't background-poll your sessions. The app shows what's running when you open it.
  • Voice or photo attachments. Coming later; not on the v1 path.

Privacy

MiniMax Remote does not transmit anything to Simple With Us. The app talks to the Mac you paired, period. Crash reports are opt-in and scrubbed of identifiers. Full notice at /privacy.

Need help?

The companion server can sometimes silently fail to start. The support page covers the four checks that catch 90% of pair failures; if those don't help, write to feedback@simplewithus.com with the output of launchctl list | grep MiniMax from your Mac.
