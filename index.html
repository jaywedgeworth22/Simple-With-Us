How This Catalog Stays Honest

A catalog is only useful if it is right.  These rules are enforced by the build, not by memory.

  • Generated From One File

    Every card is rendered from apps/index.json.  The build fails when this page and that file disagree.

  • No Dead Buttons

    An App Store or TestFlight button only appears when it points at a real listing or a public invite.  Invite-only betas say so instead.

  • Claims Link to Proof

    Each app links to its source repo or its own site, so anything said here can be checked there.

  • What Leaves Your Device

    Some apps send crash reports so bugs get fixed.  Read the privacy notice before you install, and ask us anything.
