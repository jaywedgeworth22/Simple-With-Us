ContactLogo for Mac

Support

Permissions, roster files, and known-issue reference. If the four checks below don't fix it, send the output to feedback@simplewithus.com and we'll come back the same day.

The four checks that catch 90% of match misses

  1. macOS: Contacts permission. Open System Settings > Privacy & Security > Contacts. Confirm ContactLogo is in the list and toggled on. If it isn't, launch the app once and re-check.
  2. Roster file path & format. The default roster folder is ~/Library/Application Support/ContactLogo/rosters. CSV headers must be company,domain; image folders must contain PNG or SVG named by company slug.
  3. Address Book source. Open Contacts.app, confirm the source you want branded is the default. ContactLogo writes only to the default source; other sources are skipped, not merged.
  4. Storage: undo log. If a previous batch went sideways, open Undo Log from the app menu and roll back to before that run. Logs live at ~/Library/Application Support/ContactLogo/undo.log; the last 20 batches are kept.

Crash log or "Application keeps closing"

If ContactLogo for Mac crashes on launch or while writing a batch, open Console.app and filter by process ContactLogo. Send the last ~200 lines to feedback@simplewithus.com. If you can also repro the crash, note the steps and the roster file you were using.

Brand runs but no contacts change

This is almost always a roster-format or source-selection issue. Confirm the header row is company,domain and that the roster file is in the rosters folder the app is reading. Confirm the Address Book default source in Contacts.app matches the source you expect.

Sending logs to support

The app's Help menu has a "Send Logs" action. It bundles the last few minutes into a single zip, scrubbed of your Address Book data, and opens a prefilled email to feedback@simplewithus.com. Attach the zip; we respond usually within a business day.

Contact

feedback@simplewithus.com -- open a thread, don't worry about templates. Link to your installed build if you have it (ContactLogo > About ContactLogo).
