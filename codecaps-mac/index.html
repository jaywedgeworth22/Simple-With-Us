See any cap from any window.

Mac sibling of CodeCaps. Window-level quick view per model, plus a global hotkey for any-cap status.

Download for macOS Support Privacy

What's inside

  • Window-level quick view. Hover any editor or browser; a small overlay shows caps for the model you're working in.
  • Global hotkey. One keystroke opens a compact any-cap panel. Configure the hotkey in Settings.
  • Menu-bar summary. A persistent indicator in the menu bar shows the cap closest to zero across all providers.
  • Same provider roster. Bring the keys from your iPhone -- export-import is a single file.

How it works

CodeCaps for Mac reads usage from the providers you connect, rolls up the numbers per model, and surfaces them where you're already working. The window-level overlay uses standard macOS accessibility hooks; you can disable any source app in Settings.

  1. Add a provider from the in-app list and paste your API key. Keys live in the macOS Keychain.
  2. Set the global hotkey in Settings (default: Ctrl-Shift-Caps).
  3. Hover any text input to peek at caps for the model you're typing into.

Privacy: provider keys live in the macOS Keychain. Usage numbers are stored locally. The app does not call home. Full notice at /privacy.

What it doesn't do

  • Cross-device sync. Caps and history live on this Mac. There is no account and no cloud mirror.
  • Capture input. The window-level overlay reads context from the focused app; it never reads the text you type.
  • Provider auth mediation. We never proxy your calls. The app reads usage only.

Privacy

CodeCaps for Mac does not transmit anything to Simple With Us. Provider keys live in the macOS Keychain; usage history stays on this Mac. Crash reports are opt-in and scrubbed of identifiers. Full notice at /privacy.

Need help?

If the window overlay never shows up, the Accessibility permission is almost always the cause. The support page covers the four checks that catch 90% of overlay-missing reports; if those don't help, write to feedback@simplewithus.com with the macOS version and the apps you tried hovering.
