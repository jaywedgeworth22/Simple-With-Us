CodeCaps for Mac

Support

Provider keys, Accessibility, and known-issue reference. If the four checks below don't fix it, send the output to feedback@simplewithus.com and we'll come back the same day.

The four checks that catch 90% of overlay-missing reports

  1. macOS: Accessibility permission. Open System Settings > Privacy & Security > Accessibility. Confirm CodeCaps is in the list and toggled on. Without this, the window-level overlay never appears.
  2. macOS: provider keys in Keychain. Open Settings > Providers. Each provider you want caps on must be added here; keys are stored in the macOS Keychain, never on disk in plaintext.
  3. macOS: network permission. If you use a system firewall (Little Snitch, LuLu, or the macOS app firewall), allow CodeCaps to reach your providers' usage endpoints. Denied connections show as "stale" in the dashboard.
  4. macOS: app version. Open CodeCaps > About CodeCaps. If you're on an old build, the per-model mapping can lag behind the provider's current model names. Re-download from the brand page to update.

Crash log or "Application keeps closing"

If CodeCaps for Mac crashes on launch or while pulling usage, open Console.app and filter by process CodeCaps. Send the last ~200 lines to feedback@simplewithus.com. If you can also repro the crash, note the steps and the apps you had focused.

Overlay never shows up

This is almost always Accessibility permission or an app-level opt-out. Confirm CodeCaps is in the Accessibility list under System Settings. Then open Settings > Overlay and confirm the app you were hovering is in the "Enabled sources" list -- per-app opt-out is on by default for non-editor apps.

Sending logs to support

The app's Help menu has a "Send Logs" action. It bundles the last few minutes into a single zip, scrubbed of your provider keys, and opens a prefilled email to feedback@simplewithus.com. Attach the zip; we respond usually within a business day.

Contact

feedback@simplewithus.com -- open a thread, don't worry about templates. Link to your installed build if you have it (CodeCaps > About CodeCaps).
